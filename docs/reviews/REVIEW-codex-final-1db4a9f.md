# Third audit: launch candidate 1db4a9f

Target: main commit 1db4a9fc3267ae246a4317d56a881818554e16ba, in a fresh clone on audit branch codex/final-audit-1db4a9f. No production contract behavior was changed. Fork tests used Ethereum chain ID 1 at mainnet block 26,208,025 and the deployed Artcoins v2 factory 0xC27e182ef5D8A1A7C9dd0a27414fEaBA47DF8e3c and hook 0x866f31562dDE70d7b989C2529A9DEfFfFd3bE8cc, whose record identifies source d27c932f. The pinned Jack token was fetched and built with script/tools/upstream-balance.sh at 78f3a3132725af5c1fbfb1c1d5cf09b7ccb12e16; its creation and runtime hashes matched the script pins. All broadcasts in this audit targeted local Anvil forks. No mainnet transaction was sent.

**Verdict:** The phase-one engine starts and moves under real trading fees and keeper-only automation. The candidate is not ready for the configured release gate: the pinned real-token royalty transfer fails, the upstream integration suite fails, and the freeze table still names an older candidate. The decision 167 follow-up also found a profitable held-price manipulation with an active value quote and a $29,473 real-token pool. Before the balance route or value mode is enabled, the royalty liability, quote-outage payout, ETH-pot coupling and held-price exposure need structural treatment.
