# security review of the frozen candidate 1e2c4b3 (credits engine)

reviewer: independent read only reviewer, own clone at 1e2c4b3. src/ and script/ code at 1e2c4b3 equals c8892a2 (every diff line between them is a comment), so the c8892a2 reviews apply to this code. method: full read of Core, CoreLib, FeeRouter, ControllerV1, CoreLens, the house source, every deploy script and Checks; probes on a fork (MAINNET_RPC_URL tenderly, FORK_BLOCK 26158000) in test/sec/ of the clone; one source mutation run; live chain reads. result: no critical or high finding. two medium findings sit in the launch verification, not in the contracts.

## findings, most severe first

1. MEDIUM, missing evidence + operational. CONFIG_HASH binds the config, not the code. script/Builder.sol:87 hashes `abi.encode(LaunchConfig)` and script/Deploy.s.sol:24 and Resume.s.sol:18 compare it. The Core, CoreLib, ControllerV1, FeeRouter and CoreLens that `Deploy` creates are compiled from the working tree, and postflight compares the chain with the local `out/` artifact (PostflightV2.sol:83-101, Checks `_preLibrary`), so a modified tree or a stale `out/` produces a system that passes every row. The pins of the build are the sizes in test/BuildIdentity.t.sol and the director gate of DEPLOY step 6, which sits outside the script. Failure: a dirty tree is deployed, the Core and library are immutable, the 0.069 eth factory fee is spent. Fix fits the current decisions: pin the masked runtime hashes of the five artifacts (and the creation hash of CoreLib) as constants checked by preflight and printed in the sign off table, plus a clean-tree and HEAD row.
2. MEDIUM, correctness defect of the verification. The masked identity check cannot see divergent library sites. `_idLoad` zeroes every linkReference slot (PostflightV2.sol:41-76) and `findLibrary` returns the first PUSH20 whose target is the compiled library (PostflightChecks.sol:393). Probe test/sec/SecProbeLink.t.sol: the Core has 8 PUSH20 sites of CoreLib; pointing 1 of them at a copy with one flipped byte leaves `postflightAs` with zero failed rows. A library runs by DELEGATECALL with full authority over Core storage and balance, so one foreign site is a total loss path, and the row "core: linked library is the compiled CoreLib" claims more than it proves. The same construction applies to the 12 immutables (a getter reads one site, the mask hides the others; not probed). Likelihood is low (needs a tampered build), impact is total. Fix fits: read every linkReference and immutableReference slot and require all to equal the getter value or the found library.
3. LOW, operational. Owner change env flags are honored by `Deploy` and `Resume`. SETTINGS_CHANGED, LOCKS_CHANGED, OWNER_CHANGED, COIN_CHANGED, ROUTER_CHANGED (PostflightChecks.sol:268-309, PostflightV2.sol:166-172) turn failed rows into warnings and `detectStage` returns early (SystemResumer.sol:35). Sequence: a stale `ROUTER_CHANGED=1` in the shell, `Resume` after the launch finds engine == core, returns Done and sends neither `setPayees` nor `setSplitStart`; the router split never starts and the payee share (112,778 ppm of each flush) stays with the engine until someone reads the warning. Holders lose nothing. Fix fits: `Deploy` and `Resume` revert when any of the five is set; only `Postflight` honors them.
4. LOW, correctness (grief) and owner choice. `sellForEth(ids)` without `minOut` pays `min(price state, pot)` and does not revert on a thin pot (CoreLib.sol:243, Core.sol:523). Probe test/sec/SecProbe.t.sol, test units: price state 1.672e15 per credit, a rival drains the pot to 1.096e15, the next seller of one credit is paid 1.096e15 (65.5 percent of the bid) and the credit is booked. At launch values the same shape pays 0.006 eth for a 0.0089 eth bid. The guarantee wording ("the pot covers") excludes it and INTEGRATION.md tells integrators to pass `minOut`. Owner choice: make the one argument form revert when the read is below the price state, or remove it.
5. LOW, intent mismatch (wording). ARCHITECTURE section 1 row 4 and invariant 3 say a statement sells "at or above its reserve". `sellTo` enforces the hard floor only (Core.sol:758-762). In buy only mode the house reserve is the undecayed start price (ControllerV1.statementPrice, age 0) while `buy` sells at the decayed ask (`priceOf`), so after 3 hours a sale clears at 109 percent against a 110 percent reserve and later down to the 75 percent floor. Consistent with FLOW 56 and invariant 12; the guarantee should say hard floor. Needs a wording choice by the owner, no code change.
6. INFO, cleanup. SPEC.md:334 (section 14 item 22) still gives the `rateStart` input range as [1e11, 1e15]; code and sections 2 and 3 say [1e13, 1e18]. Prior finding next29 #3 is closed except this line.
7. INFO, bounds. The stored rate has no lower bound: `drop` can reach 0 from 1 wei and `_climb` never lifts r == 0 (CoreLib.sol:232). Reaching it from 8.9e15 needs ln(8.9e15)/0.005, about 7,300 consecutive credits with no climb back, each sold at a falling bid, so a seller pays far more than it gets. `setRate` restores the bid. A shallow drag (about 0.5x of the price state) costs the seller roughly 0.3 eth of discount and the bid recovers by climb in about 2.2 hours at idleLoosenBps 2_000 (OD-3, decision 50).
8. INFO, operational, read live at block 26164762. Owner 0xCB43 nonce 3835 (3822 at 26163823), balance 0.0163 eth against 0.069 eth fee plus gas (preflight row, expected). Any owner transaction between preflight and the last deploy transaction moves the CREATE addresses; the Core constructor then reverts on a router without code, so the failure is gas only. Delegation pins hold now: code 0xef0100612373d7003d694220f7800eeaf8e3924c0951d3, delegate codehash 0xff0357b5...d631, keyCount 0, version Uniswap.Calibur.1.0.0.

## verified sound
- Pot and balance tie out on every eth path: sellForEth, buyListing (cost = balance fall, `_spend(cost + tip)`), sellTo and collectSales (`_book`), receive (router only), buyback (`ethToBuyback -= slice`, `+= slice - spent - tip`), `_repay`, migrate, skim. A seller acting as the keeper cannot exceed the ceiling: cost + min(10 percent of savings, 2 percent of cost) peaks at cost = ceiling. A donation inside the target call lowers the caller's own proceeds and is booked later by `skim`.
- Reentrancy: every state changing door is nonReentrant (solady slot shared with the library `_enter` and `_leave`); `receive` reverts only for the router while `MEASURING` is set; `unlockCallback` accepts the pool manager only; owner functions are owner gated in the library. Router payees get 100,000 gas under `_busy`; `pullFees` caps the flush at 1,000,000 gas and ignores failure.
- Approvals: stranger `STATEMENTS.compose` on 80 Core pile credits reverts, stranger `CREDITS.transferFrom(core, ...)` and `STATEMENTS.transferFrom(core, ...)` revert (test/sec/SecProbe.t.sol). `buyListing` forbids Credits, Statements, coin, exit module, exit token, hook, manager, factory, locker, escrow, router, house, Permit2, position manager, universal router; the Core has no fallback and no ERC1271, so Seaport cannot treat it as an offerer.
- Library: non view CoreLib functions revert outside DELEGATECALL; direct calls read zero owner storage. Storage mirror CoreState equals Core declaration order (CoreLayout test). `retired` and the four locks are written once (grep), never cleared.
- House: contract recipients are never pushed, proceeds go to `pendingRefunds` and are pulled by `collectSales`; word offsets W_FIRST 2, W_AMOUNT 3, W_RESERVE 4, W_OWNER 5, W_END 7 match the Auction struct; house per sender clone, fee fixed at creation, postflight requires fee 0.
- Statements: `supply()` is a mint counter. 12 of 176 mainnet ids are burned and `supply()` is 176, so `compose`'s `sid == supply()` check cannot be bricked by burns. Credits ids start at 1 (`ownerOf(0)` is nonexistent), matching the id 0 sentinel.
- Rate math: no overflow path in `_climb` (lastFillRate <= 1e18, loosened < 1e10, ceilBps <= 3e4, `expWad` input guarded by the `lnWad(target/r)` test), never reverts from `receive`. Documented timings reproduce: 2x in 140 minutes, 4x in 279 minutes at 0.5 percent a minute.
- Constants match the canonical mainnet addresses (Seaport 1.6, Permit2, universal router, position manager). Owner delegate pins verified live (finding 8). Settings struct: 26 fields in SettingsBounds, unpack, SetSettings TUPLE and mainnet.json.
- Targeted tests, all pass on the fork: Config 33, Migrate 36, Rescue 13, FeeRouter 29, Lock 8, OwnerPowers 7, PullFees 17, SetSettings 10, Resume 22, Adopt 21, ReviewDeploy 17, FeeShare 10, plus the two probe files.
