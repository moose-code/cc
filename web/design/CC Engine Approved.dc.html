05
dark mode
system
tokens, rules and components for building both themes
dark mode
black paper
dark mode is the same print system on black stock. layouts, type and spacing don't change; only the tokens do. build both themes from the table on the right.
01
black paper, white art
the page turns black. credits and statements always print on their own white paper, so the artwork is identical in both modes.
02
the key plate prints white
everything that was black ink becomes off-white: text, filled buttons, selection, the K cell edge.
03
inks keep their values
C, M and Y are unchanged. where they overlap, as in the logo, blend with screen instead of multiply.
04
structure softens
section rules drop to #55534e so the grid reads without glare. row hairlines go almost black.
05
filled controls invert
the primary button, active toggle and the pot cell become off-white with black text.
06
one token set
every colour is a variable with a light and a dark value. pages never set colours directly.
switching
defaults to the system setting. a three-way control in the footer (auto · light · dark) overrides it and is remembered on the device. no animated transition.
